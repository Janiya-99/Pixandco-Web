# Northline Systems

A premium editorial AI and automation studio website built with Next.js App Router, strict TypeScript, Tailwind CSS, Motion, Lenis, Radix-based shadcn-style UI primitives, Lucide icons, and Zod.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Checks

```bash
npm run typecheck
npm run build
```

The contact endpoint validates submissions but intentionally does not send email until a provider is configured.
